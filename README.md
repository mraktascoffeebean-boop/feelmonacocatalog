# Man & Woman All Parfum List

Mobil uyumlu Turkce parfum katalog uygulamasi. Uygulama tamamen statik calisir; sunucu, veritabani veya kurulum gerektirmez.

## Dosyalar

- `index.html` - Uygulama sayfasi
- `styles.css` - Panel ve mobil tasarim
- `app.js` - Parfum katalog verisi, filtreleme, arama ve detaylar
- `feel-monaco-logo.png` - Feel Monaco logosu
- `.nojekyll` - GitHub Pages'in dosyalari dogrudan yayinlamasi icin

## GitHub Pages'te yayinlama

1. GitHub'da yeni bir repo olustur.
2. Bu klasordeki dosyalari repoya yukle.
3. GitHub reposunda `Settings` bolumune gir.
4. `Pages` sekmesini ac.
5. `Build and deployment` kisminda `Deploy from a branch` sec.
6. Branch olarak `main`, klasor olarak `/root` sec.
7. Kaydet.

Birkac dakika sonra uygulama su formatta acilir:

```text
https://kullanici-adin.github.io/repo-adi/
```

## Mobilde acma

GitHub Pages linkini telefonda acman yeterlidir. Uygulama mobil ekrana gore otomatik duzenlenir.
